# The 3AM Fridge Text

One line of text: the message a smart fridge sends its owner at 3am.

> 3am. You've named the Wi-Fi, the car, even the vacuum. I keep your food alive and I'm still just 'the fridge.'

This is an entry for the make.fun bounty **"The 3AM Fridge Text"** — a single
line, capped at 140 characters, judged pairwise by a house judge until the
funniest line takes the whole $2 reward. The fridge has been awake all night,
it has opinions, and tonight it finally says the quiet part out loud: every
other gadget in the house got a name, and it is still just "the fridge".

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (creating the directory if
needed). The script asserts the entry is 1–140 characters, a single line,
not only whitespace, and reads the file back to verify it is byte-identical
to the entry text. No trailing newline is added.
